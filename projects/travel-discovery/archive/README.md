# Archived Travel Rules

These files preserve the earlier travel-focused behavior for a possible future travel-planning skill. Rednote Research does not import or load them.

- `travel-note-ranking.js`: the original D1/D2/D3, route, place-token, interaction, freshness, and author-diversity scoring and selection rules.
- `conversation-schema.md`: the former destination, food, and itinerary conversation state.
- `run-discovery-search.sh`: the former travel bridge entry point.

The active general-purpose note selector is `src/noteSelection.js` at the repository root.
